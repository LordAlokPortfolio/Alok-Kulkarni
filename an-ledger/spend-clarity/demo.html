Spend Clarity

Spending variance visualized

This component reveals spending patterns and anomalies that bar charts hide. Click any petal to see the transactions behind it.

Use this in your app:
  • Financial advisor dashboards, to show clients their cashflow
  • Credit card apps, to help customers understand spending shifts
  • Banking apps, to flag budget anomalies automatically
  • Any platform that takes transaction data and needs a visual story

Three months, three stories

Same component, same data, three different comparisons. The inner grey petal is the baseline month; the coloured petal over it is the target month.

Over baseline by 20%+ Under baseline by 5%+ Effectively flat

Each category is compared against the same category in the baseline month:

variance = (target − baseline) / baseline

  • variance > 0.20 → red petal (spending grew 20% or more)
  • variance < -0.05 → green petal (spending fell more than 5%)
  • otherwise → grey petal (effectively flat)
  • baseline of zero → red if there is new spending, grey if still zero

Petal length is proportional to the square root of the amount, because a petal's visual weight is its area. Scaling length linearly would make twice the spending look four times as big.

Thresholds and colours are constants at the top of spend-clarity.js, meant to be tuned per product.

Drill-down

The component returns an SVG string and nothing else. Every petal carries data-category, so this page attaches its own click listener — your app would do the same and open whatever UI it likes.

Click a petal above to see its transactions.

Spend Clarity runs entirely in the browser: no server, no API key, no login, no dependencies. Open this file by double-clicking it.
