Household dashboard

The whole household across every card, in one file. Pick one or more exports (.csv or .xlsx) — selecting several loads and merges them together. Adds Card and Person to the usual columns, so spending can be filtered by who spent it and which card it came off. Any metadata rows above each file's real table are skipped automatically. Nothing leaves this machine except the merchant, amount, and (when the file has them) description/address/city fields you explicitly send to OpenAI to categorize.
